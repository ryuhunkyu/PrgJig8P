# PrgJig8P
MCU 8Port Programmer Jig 

[260913:기본 기능 설명서]
기본적인 설계내용은 program code에 올려져 있다.
제품의 목적은 embedded 전자회로물을 생산시 각 PCB를 1개씩 Program하는 방식으로 하였는데 
생산업체에서 인력문제 때문에 이 일을 좀 더 빨리 할 수 있는 방법을 제공하여 비용을 절감하려고 하는 것이다. 

지금은 단순히 Program만 빨리 할 수 있으며 다른 기능은 없다. 
8채널인 이유는 보통 PCB Array를 8개 이내에서 하기 때문이며 그 이상은 별도로 다시 만들어야 한다. 
작업자는 단순히 전원을 공급하고 별도 포고핀이 설치된 확장 PCB Array기판을 만들고 
기판 고정장치도 따로 제작해야 한다. 
그것까지 이 프로젝트에 포함되지는 않는다. 그것은 기계파트에서 작업할 일의비중이 더 크다. 

이 제품의 작동은 기본적으로 PC(computer)상에서 작동하는 각종 programing 환경을 
그대로 쓰는데 마우스로 버튼을 클릭하면 Program이 시작되는 점을 이용한다. 

Program Button을 누르면 8개 중에 선택된 하나의 포트로 PC의 program signal을 연결하면 
그대로 선택된 Port에 연결된 PCB의 MCU만 Program되는 것이다. 

기타 나머지 세세한 조작은 소스 코드 안에 scenario section에 설명되어있다. 

이 제품은 program성공/실패를 알지 못한다. 

작업자가 컴퓨터를 보고 판단해서 program을 Stop시켜 다시 할 수도 있지만 
기본적으로 아주 단순한 기능을 제공한다.
