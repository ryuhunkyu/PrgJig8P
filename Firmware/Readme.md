<프로젝트에서 수행하는 작업>
Project:	MCU Programming 8Port Jig
		MCU를 사용하는 전자회로를 생산 할 때 MCU를 Program하는 Tool
		최대 8개의 PCB Array를 접속할 수 있다.

<프로젝트가 유용한 이유>
기존 생산 방식으로 Program할 경우와 대비하여 우수한 시간 절약 효과가 있다

<사용자가 프로젝트를 시작하는 방법>
이 프로젝트는 Microchip, Atmel, Latice 등의 회사에서 지원하는 Programming Tool을
접속하여 신호를 8Port까지 확장할 수 있으며 1개씩 순서대로 프로그램을 지원한다.

<사용자가 프로젝트와 관련된 도움을 받을 수 있는 위치>

<프로젝트를 유지 관리하고 기여하는 사람>
황병국: 이 프로젝트를 처음 제안한 인물이며 주변의 생산 공장에 소개할 것이라고 하였다.
